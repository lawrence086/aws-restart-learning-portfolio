## Topics

### Computing and cloud foundations

- Introduction to computing and basic computing concepts.
- Roles in a development team and cloud careers.
- What cloud computing is, its advantages and what AWS provides.
- AWS pricing fundamentals, global infrastructure and service categories.
- Shared responsibility, Amazon S3 and Amazon EC2.

### Linux

The command line, users and groups, file editing, the filesystem, permissions, processes, services, the Bash shell, scripting, software management and logs.

### Networking

| Area | Topics |
| --- | --- |
| Models and protocols | OSI/TCP-IP models and how protocols fit together |
| Addressing | IPv4 addressing, CIDR and subnetting |
| Common services | DNS, DHCP and HTTP |
| AWS networking | VPCs, subnets, route tables and gateways |
| Traffic controls | Security groups, network ACLs and firewalls |
| Connectivity | Private and hybrid connectivity concepts |
| Troubleshooting | Testing connections and distinguishing routing, port and application problems |

### Security

- Security principles and shared responsibility.
- IAM identities, groups, roles and policies.
- Encryption, KMS and protecting secrets.
- TLS, certificates and public key infrastructure.
- System hardening, updates and patch management.
- Detection, incident response and compliance, including CloudTrail and Config concepts.

### Python and development practices

- Programming basics, numeric and string values, conversions and input/output.
- Lists, tuples, dictionaries and mixed data.
- Conditions, loops, functions, parameters, arguments and return values.
- Modules, CSV/JSON files, exceptions and small administration scripts.
- Debugging, testing and checking results.
- Version control with Git.
- DevOps, continuous integration/delivery and configuration management concepts.

See the [Python exercises](lab-index.md#python) for the practice covered in this part of the programme.

### Databases

| Area | Topics |
| --- | --- |
| Foundations | DBMS concepts, relational and non-relational databases, schemas and ACID transactions |
| Structure and changes | Table creation, data types, keys, constraints, DDL/DML/DCL, inserts, updates and deletes |
| Working with data | CSV import/export, cleaning data, DESCRIBE, NULL handling, TRIM and CONCAT |
| Queries | SELECT, aliases, conditions, filtering and sorting |
| Transforming results | String and numeric functions, aggregates, grouping and window functions |
| Relationships | Joins, subqueries and relational modelling |
| Safe operations | Transactions, query safety and performance concepts |
| AWS services | RDS, Aurora and DynamoDB |
| Operations and analytics | Backups, availability, migration, Redshift and related analytics concepts |
| Local revision | A fictional shop dataset used for [SQL practice](sql/README.md) |

### AWS architecture and operations

- Cloud Adoption Framework and Well-Architected principles.
- AWS CLI, SDKs, instance metadata and Systems Manager.
- EC2 instances, images, bootstrapping and lifecycle management.
- Application Load Balancers and Auto Scaling.
- Route 53, DNS routing and CloudFront.
- S3 websites, object protection, block/file storage and backups.
- Elastic Beanstalk, Lambda, APIs and Step Functions.
- Containers, ECS, EKS and Fargate concepts.
- Monitoring, logging, auditing, reliability and recovery.
- Accounts, Organizations, tags, costs and support.
- JSON/YAML, infrastructure as code, CloudFormation and delivery automation.
- Machine learning workflows, responsible AI, SageMaker Canvas, Bedrock, retrieval, agents and Amazon Q Developer.

See the [AWS and database exercises](lab-index.md#aws-and-databases) for the lab write-ups.
