# Updating an S3 website

I worked with the training bakery website, edited its CSS in Vim and used a Bash upload script to copy the updated site files to S3. I then checked the website to see the change.

This connected a local edit with the version served from object storage. It also gave me practice checking the source folder and upload destination when a page did not reflect the expected file.
