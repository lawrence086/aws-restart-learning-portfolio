# SQL lab work

I practised creating and changing records, selecting columns, aliases, sorting and filters using WHERE, BETWEEN and LIKE. Later exercises used string functions, DISTINCT, aggregate functions, GROUP BY, window totals and regional ranking.

In one exercise, a statement without a `WHERE` clause affected every row. I restored the supplied world dataset. Now I check which rows match with a `SELECT` before I run an `UPDATE` or `DELETE`.

The grouping and window exercises also helped me distinguish one result per group from a calculation that keeps the individual rows.
