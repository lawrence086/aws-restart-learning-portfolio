# Managing instances with Systems Manager

I used inventory, associations and Run Command to inspect managed instances and configure Apache/PHP. I also worked with a Parameter Store value used as a feature switch and accessed an instance through Session Manager.

I practised patching three Linux and three Windows nodes using security patch baselines, a Windows production tag and an approval delay. I fixed a conflicting baseline association and checked that all six nodes showed as compliant with the selected baselines.

I now check which baseline is associated with a node before interpreting its compliance status.
