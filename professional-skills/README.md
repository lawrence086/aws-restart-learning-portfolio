# Professional skills

I practised explaining technical work, giving updates and preparing for interviews during AWS re/Start.

The [programme coverage map](../learning-map.md#professional-and-career-skills) lists the sessions, including career goals, leadership principles, digital presence, resumes, networking and interview preparation.

## Troubleshooting

In the [EC2 lab](../aws-labs/ec2.md), I checked the region, security group, application port and startup script while working through a launch error and a website connectivity problem.

I try to change one thing at a time and test again. When I ask for help, I explain what I expected, what happened and what I’ve already tried.

## Explaining my work

For a short demo, I start with the task, show the result and explain one decision or problem I worked through. For an interview example, the Situation, Task, Action, Result structure helps me stay focused.

## Working with others

In a team update, I explain what I’ve finished, where I’m stuck and what help I need. The communication sessions also covered listening and asking questions in meetings.
